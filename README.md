# Оптовая торговля офисной мебелью со склада

Проект учебной практики студента Каюмова Тимура Виленовича,
группа ИКБО-15-24.

## Назначение

Автоматизация обработки оптового заказа офисной мебели:
создание заказа, расчёт стоимости, резервирование,
контроль оплаты, комплектование и отгрузка.

## Средства разработки

- Windows.
- Python 3.11.9.
- PyCharm.
- Git.
- Java и PostgreSQL — подключаются на следующих этапах.

## Структура проекта

- data — учебные данные.
- db/migrations — изменения структуры базы данных.
- docs — документация.
- docs/screenshots — иллюстрации для отчёта.
- java — объектно-ориентированная реализация.
- models — модели процесса и данных.
- python — процедурная реализация.
- tests — проверки программного решения.
- check_environment.py — проверка рабочего окружения.

## Проверка окружения

Из корневой папки проекта:

    python check_environment.py

## Текущее состояние

Подготовлена структура проекта.
Реализация бизнес-операций и базы данных выполняется поэтапно.

В проекте используются только вымышленные учебные данные.
